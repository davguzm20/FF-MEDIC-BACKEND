# Guía de Estilo para Documentos en Summary

## Títulos

- Un solo `# Título del Documento` al inicio
- `##` para secciones principales
- `###` para subsecciones
- `####` para ítems individuales
- Sin numeración estilo Word
- Sin anclas HTML

## Encabezados

- Sin portada con autores, versión o historial de cambios dentro del archivo
- Sin índice generado automáticamente
- Sin imágenes base64

## Tablas

- Usar alineación simple sin modificadores
- Sin combinaciones de celdas
- Sin etiquetas HTML dentro de celdas

## Separadores

- Usar `---` entre secciones principales
- Sin líneas en blanco excesivas
- Sin headings vacíos

## Listas

- Usar `-` para bullet points
- Usar `1.` para listas numeradas

## Énfasis

- **negrita** para campos o labels
- *cursiva* para notas o referencias

## Bloques de cita

- Usar `>` para notas, referencias a documentos externos o hitos

## IDs

- Formato: código-guion-número
- Sin espacios entre código y número

## Archivos

- Sin referencias a imágenes embebidas
- Usar kebab-case para nombres de archivos y carpetas
